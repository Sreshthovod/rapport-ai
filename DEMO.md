## 2. Live Demo Script & Scenarios

### Scene 1: The Hook (0:00 - 0:30)
> *"We spend 4 hours a day on Slack and WhatsApp. But high-velocity chat is broken. We drop promises made in fast threads, send impulse messages late at night, and agonize over phrasing. Existing AI tools like Grammarly just check your spelling, and ChatGPT requires copy-pasting your confidential chats into a cloud box.*  
> *Meet **Rapport AI** — an interpersonal intelligence engine operating directly inside your chat DOM, powered by a 100% local, privacy-first relationship memory graph."*

### Scene 2: Live Scenario 1 — Commitment Guardrail (0:30 - 1:15)
* **Action**: Presenter opens Slack Web channel `#client-acme` with contact "Sarah Jenkins".
* **Presenter Voiceover**: *"Watch what happens when I open Slack to chat with Sarah. Yesterday in this thread, I promised to send the Q3 Slide Deck by 4 PM. I forgot."*
* **Live Action**: Presenter starts typing a casual sign-off: *"Hey Sarah, thanks for the sync, talk to you tomorrow!"*
* **Visual Climax**: Instantly, an amber line-of-sight badge flashes directly above the input box:  
  `⚠️ Pending Commitment: "Send Q3 Slide Deck by 4 PM"`
* **Presenter Voiceover**: *"Rapport's local memory engine catches the dropped ball before I hit send. One click on `[ Resolve Commitment ]`, and it streams a perfect, polite status update right into Slack."* (Hits `Tab` to insert).

### Scene 3: Live Scenario 2 — De-Escalation Brake (1:15 - 1:55)
* **Presenter Voiceover**: *"Now let's look at emotional friction. It's late, you're stressed, and an annoying bug breaks staging."*
* **Live Action**: Presenter types an aggressive draft into Slack: *"Why haven't you fixed this bug yet? This is completely unacceptable."*
* **Visual Climax**: Before the presenter can hit enter, the assistant flashes a soft red alert:  
  `🛑 Tone Alert: Hostile / Passive-Aggressive`  
  `Suggested Rephrase: "Let's figure out what blocked the staging fix so we can resolve this together."`
* **Presenter Voiceover**: *"Press `Tab`, and Rapport replaces the emotional impulse with a constructive rephrase that saves the working relationship."*

### Scene 4: The Mic Drop & Privacy Moat (1:55 - 2:30)
* **Action**: Open Extension Sidepanel showing the Local Memory Inspector.
* **Presenter Voiceover**: *"Here is the kicker: zero cloud retention. Every contact note, commitment log, and style profile is stored exclusively on your device inside browser IndexedDB using local vector indexes. Your private Slack chats never train a cloud model.*  
* **Rapport AI**: Stop typing sentences. Start managing relationships. Thank you!"*

## 3. Judge Questions & Defensible Answers

### Q1: "Why won't OpenAI or Slack just build this into their app?"
* **Answer**: *"Slack will never build this for WhatsApp, and WhatsApp will never build this for Slack. We provide cross-platform ecosystem neutrality. Furthermore, big tech business models rely on cloud data collection; our strict local-first architecture provides an unassailable privacy guarantee for sensitive executive, legal, and financial messaging."*

### Q2: "Isn't DOM scraping fragile when Slack or WhatsApp update their apps?"
* **Answer**: *"We use a resilient multi-fallback selector engine with MutationObservers and Shadow DOM encapsulation. Even if host CSS changes completely, our content script falls back to native contenteditable listeners and floating viewport anchors."*

### Q3: "How do you stop AI suggestions from sounding like fake corporate fluff?"
* **Answer**: *"We don't replace user drafts with full generic generation. We perform micro-calibrations and diff-rephrasing directly on the user's authentic draft text, matching recipient-specific brevity and formality profiles stored in local memory."*

## 4. Fallback Strategies (In Case of Live Issues)

- **Internet Outage during Live Demo**: Toggle Hono backend to pre-cached local stub responses; presentation continues seamlessly.
- **Slack Web Layout Shift**: Keep a secondary WhatsApp Web tab open and warm as immediate backup surface.
- **Backup Recording**: Pre-recorded 1080p 60fps video snippet saved to Desktop ready to play in 1 click if browser freezes.
